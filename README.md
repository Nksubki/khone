# 🏗️ حساب‌کتاب ساخت‌وساز (خونه)

برنامه حسابداری فارسی برای ثبت و بررسی هزینه‌های پروژه‌های ساختمانی — با **جنگو، HTML و CSS خالص**.
کاملاً راست‌به‌چپ، با **تاریخ شمسی**، **ساعت تهران**، **ورودی صوتی فارسی** و **چند کاربره (شریک‌ها)**.

بدون هیچ کتابخانه اضافه: تبدیل تاریخ شمسی و تبدیل «صد و بیست میلیون» به عدد، همه در همین پروژه پیاده‌سازی شده است.

---

## ✨ امکانات

### ثبت هزینه
- مبلغ را **تایپ** کنید یا با **میکروفون فارسی** بگویید:
  «صد میلیون» → ۱۰۰,۰۰۰,۰۰۰ · «دو میلیارد و سیصد میلیون و پانصد هزار» → ۲,۳۰۰,۵۰۰,۰۰۰
- توضیحات و نام فروشنده هم با میکروفون قابل نوشتن است.
- زیر فیلد مبلغ، عدد به **حروف** نشان داده می‌شود تا اشتباه نشود.
- دکمه‌های سریع: +۱ میلیون، +۵ میلیون، +۱۰ میلیون، +۱۰۰ میلیون.
- **تاریخ شمسی** به‌طور خودکار روی «امروز به وقت تهران» تنظیم می‌شود و با تقویم فارسی یا تایپ قابل تغییر است
  (میان‌بُرها: امروز، دیروز، ۲ روز پیش، هفته پیش). روز هفته هم زیر فیلد نمایش داده می‌شود.
- ساعت، طرف حساب، نحوه پرداخت (نقدی، کارت به کارت، حواله، چک، نسیه) و **عکس فاکتور/رسید**.
- دو نوع رکورد: **هزینه** و **دریافت/واریز** (مثلاً آورده شریک) تا مانده صندوق مشخص باشد.
- دکمه «ثبت و رکورد بعدی» برای ثبت پشت‌سرهم.

### دسته‌بندی‌ها
- ۲۳ دسته‌بندی آماده (میلگرد و آهن، سیمان و گچ، آجر و بلوک، شن و ماسه، بتن، دستمزد کارگر،
  دستمزد بنّا، تأسیسات برقی، لوله‌کشی، کاشی و سرامیک، درب و پنجره، نقاشی، ایزوگام، اجاره جرثقیل،
  حمل‌ونقل، عوارض شهرداری، مهندس و نقشه‌کشی، داربست، متفرقه، آورده شریک، فروش واحد، وام،
  سایر دریافتی‌ها).
- هر تعداد دسته دلخواه با **نام، آیکن و رنگ** اضافه کنید — آیکن‌ها از یک مجموعه
  **۶۹ آیکن SVG** (میلگرد، کیسه سیمان، آجر، جرثقیل، کلاه کارگر، ماله، …) انتخاب می‌شوند.
- **ساخت دسته جدید بدون ترک فرم ثبت هزینه** (دکمه «دسته جدید»).

### فیلترهای قوی
- بازه‌های آماده: امروز، دیروز، این هفته، این ماه، ماه گذشته، ۳۰ روز اخیر، این فصل، امسال، سال گذشته، همه.
- بازه دلخواه: **از تاریخ … تا تاریخ …** (شمسی).
- فیلتر چندتایی روی **دسته‌بندی‌ها** و **کاربران** (مثلاً «فلان شریک این ماه چقدر خرج کرده؟»).
- فیلتر پروژه، نحوه پرداخت، حداقل/حداکثر مبلغ، جستجوی متنی در توضیحات و طرف حساب.
- ترتیب دلخواه (تاریخ، مبلغ، آخرین ثبت) و **خروجی CSV سازگار با اکسل**.
- در هر فیلتر: جمع کل، تعداد، میانگین، مانده، و تفکیک زنده بر اساس دسته و کاربر.

### گزارش‌ها
- نمودار ۱۲ ماه اخیر (ماه‌های شمسی) و نمودار ۱۴ روز اخیر.
- تفکیک بر اساس دسته‌بندی، کاربر، پروژه و نحوه پرداخت با درصد سهم هر کدام.
- ۱۰ رکورد بزرگ هر بازه.

### کاربران و شرکا
- مدیر می‌تواند برای هر شخص **نام کاربری و رمز** بسازد، رمز را عوض کند یا حساب را غیرفعال کند.
- سه نقش:
  | نقش | دسترسی |
  |---|---|
  | **مدیر** | همه‌چیز؛ ساخت کاربر، ویرایش/حذف رکورد دیگران، حذف دسته‌بندی |
  | **شریک** | ثبت/ویرایش رکورد خودش، ساخت دسته‌بندی، دیدن گزارش‌ها |
  | **ناظر** | فقط مشاهده |
- گزینه «فقط رکوردهای خودش را ببیند» برای هر کاربر.
- **گزارش فعالیت‌ها**: هر ثبت، ویرایش، حذف و ورود ثبت می‌شود (شفافیت بین شرکا).

### پروژه‌ها (اختیاری)
- برای چند ساختمان/کارگاه، هر کدام یک پروژه با **بودجه** و نوار پیشرفت مصرف بودجه.

### خوانایی برای چشم‌های ضعیف
- **پنج اندازه متن** (کوچک، معمولی، بزرگ، خیلی بزرگ، بزرگ‌ترین) با دکمه «آ» در نوار بالا
  و همچنین در صفحه «حساب من» با پیش‌نمایش زنده.
- انتخاب اندازه در همان گوشی ذخیره می‌شود؛ پس اگر فامیل شما یک‌بار «بزرگ‌ترین» را انتخاب کند،
  همیشه همان می‌ماند و روی گوشی شما تغییری نمی‌کند.
- اندازه پیش‌فرض ۱۷ پیکسل است (بزرگ‌تر از حالت معمول سایت‌ها) و هیچ متنی در برنامه
  کوچک‌تر از حد خوانا نیست (با تست خودکار بررسی می‌شود).
- با انتخاب اندازه‌های بزرگ، **کل چیدمان** با هم بزرگ می‌شود (دکمه‌ها، آیکن‌ها، فاصله‌ها)
  و مبلغ هر رکورد در خط جداگانه و درشت نمایش داده می‌شود تا خوانا باشد.
- کنتراست متن‌ها بالا برده شده و همه دکمه‌ها حداقل اندازه لمسی استاندارد را دارند.

### ظاهر
- طراحی مدرن راست‌به‌چپ، **کاملاً ریسپانسیو** برای گوشی، تبلت و دسکتاپ
  (بریک‌پوینت‌ها: ۳۴۰، ۴۰۰، ۴۳۰، ۴۸۰، ۵۶۰، ۷۰۰، ۸۲۰، ۱۰۲۴، ۱۲۰۰، ۱۴۰۰ پیکسل + حالت افقی گوشی).
- **همه آیکن‌ها SVG خطی هستند** (بدون ایموجی) — یکدست در همه دستگاه‌ها، رنگ‌پذیر و
  با کیفیت در هر اندازه صفحه. آیکن‌ها به‌صورت اسپرایت درون صفحه درج می‌شوند
  (بدون درخواست شبکه اضافه و سازگار با سافاری آیفون).
- روی موبایل: منوی پایین + دکمه گرد ثبت سریع. روی دسکتاپ: نوار کناری.
- **حالت روشن و تیره** (ذخیره در همان مرورگر) و استایل مناسب چاپ.

## 🚀 نصب و راه‌اندازی

نیاز: **پایتون ۳٫۱۰ یا بالاتر**.

### روش ساده

**ویندوز:** روی فایل `setup.bat` دوبار کلیک کنید.

**لینوکس / مک:**
```bash
bash setup.sh
```

اسکریپت، محیط مجازی می‌سازد، جنگو را نصب می‌کند، دیتابیس را آماده می‌کند و از شما
نام کاربری و رمز مدیر را می‌پرسد.

### روش دستی

```bash
python -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate
pip install -r requirements.txt

python manage.py makemigrations ledger
python manage.py migrate

# ساخت حساب مدیر + دسته‌بندی‌های پیش‌فرض
python manage.py init_app --username admin --password 123456 --name "علی محمدی"

python manage.py runserver
```

سپس در مرورگر: <http://127.0.0.1:8000>

### استفاده از گوشی در خانه / کارگاه

```bash
python manage.py runserver 0.0.0.0:8000
```
آدرس `http://IP-کامپیوتر:8000` را در گوشی باز کنید (هر دو دستگاه روی یک وای‌فای).

## 🎤 میکروفون روی آیفون و اندروید (مهم)

مرورگرها به دلایل امنیتی، دکمه میکروفون سایت را **فقط در آدرس‌های امن** فعال می‌کنند:
`localhost` یا آدرس‌های **HTTPS**. اگر برنامه را با آدرسی مثل `http://192.168.1.5:8000`
روی گوشی باز کنید، دکمه میکروفون کار نمی‌کند (خود سافاری اجازه نمی‌دهد).
برنامه این موضوع را تشخیص می‌دهد و با پیام فارسی و راه‌حل به شما می‌گوید.

### راه ۱ (ساده‌ترین، همین حالا کار می‌کند): میکروفون کیبورد گوشی
روی فیلد **مبلغ** ضربه بزنید تا کیبورد باز شود، بعد **آیکن میکروفون خودِ کیبورد آیفون**
را بزنید و بگویید: «صد و بیست میلیون».
برنامه همان متن فارسی را **خودش به عدد تبدیل می‌کند** و مبلغ را به‌صورت
`۱۲۰,۰۰۰,۰۰۰` ذخیره می‌کند. برای توضیحات هم همین کار را بکنید.

> پیش‌نیاز: کیبورد فارسی نصب باشد و `Settings › General › Keyboard › Enable Dictation` روشن باشد.

### راه ۲ (برای فعال شدن دکمه میکروفون خود برنامه): یک آدرس HTTPS بسازید
با یک تونل رایگان، برنامه محلی شما یک آدرس HTTPS واقعی می‌گیرد و میکروفون کامل کار می‌کند:

```bash
# ترمینال ۱
python manage.py runserver 0.0.0.0:8000

# ترمینال ۲ (cloudflared را از سایت Cloudflare نصب کنید)
cloudflared tunnel --url http://localhost:8000
```
آدرسی مثل `https://xxxx-yyyy.trycloudflare.com` به شما می‌دهد؛ همان را در گوشی باز کنید.
دامنه‌های `trycloudflare.com`، `ngrok-free.app`، `loca.lt` و `serveo.net` از قبل در تنظیمات
برنامه مجاز شده‌اند و نیازی به تغییر چیزی نیست.

جایگزین‌ها: `ngrok http 8000` یا `npx localtunnel --port 8000`.

### راه ۳: تایپ دستی
همه امکانات دیگر برنامه بدون میکروفون هم کامل کار می‌کند.

### وقتی دکمه میکروفون کار می‌کند
- روی **کروم** (اندروید/ویندوز/مک) و **سافاری آیفون ۱۴٫۵ به بالا** پشتیبانی می‌شود.
- بار اول، مرورگر اجازه دسترسی می‌خواهد؛ اگر رد شد، پنل برنامه دکمه
  «اجازه دسترسی به میکروفون» را نشان می‌دهد و راهنمای
  `Settings › Safari › Microphone › Allow` را می‌دهد.
- بعد از گفتن مبلغ، برنامه **چند حدس** تشخیص گفتار را نشان می‌دهد تا اگر حدس اول درست
  نبود، با یک ضربه درستش را انتخاب کنید (برای کم کردن خطا).
- حدس‌ها امتیازدهی می‌شوند: حدسی که به عدد قابل تبدیل باشد و مبلغ «گردتری» بدهد
  (مضرب هزار/میلیون) در اولویت است.

### دقت تبدیل گفتار به عدد
پارسر فارسی برنامه این حالت‌ها را درست می‌فهمد (همه تست‌شده‌اند):

| گفته / نوشته | نتیجه |
|---|---|
| صد میلیون | ۱۰۰,۰۰۰,۰۰۰ |
| صد و بیست میلیون | ۱۲۰,۰۰۰,۰۰۰ |
| دو میلیارد و سیصد میلیون و پانصد هزار تومان | ۲,۳۰۰,۵۰۰,۰۰۰ |
| یک میلیون و نیم | ۱,۵۰۰,۰۰۰ |
| نیم میلیارد | ۵۰۰,۰۰۰,۰۰۰ |
| سی صد میلیون *(خطای رایج تشخیص گفتار)* | ۳۰۰,۰۰۰,۰۰۰ |
| هشتاد و پنج میلیون و چهارصد و پنجاه هزار | ۸۵,۴۵۰,۰۰۰ |
| ۲/۵ میلیون یا ۲.۵ میلیون | ۲,۵۰۰,۰۰۰ |
| 100.000.000 | ۱۰۰,۰۰۰,۰۰۰ |
| لطفا صد میلیون ثبت کن *(واژه‌های اضافه نادیده گرفته می‌شوند)* | ۱۰۰,۰۰۰,۰۰۰ |

واژه‌های اضافه («بابت»، «تومان»، «لطفا»، «هزینه»، …) نادیده گرفته می‌شوند و شکل‌های
غلط رایج («ملیون»، «میلیارت»، «پان صد»، «دو یست») هم اصلاح می‌شوند.
مبلغ نهایی همیشه زیر فیلد **به حروف** نشان داده می‌شود تا قبل از ثبت چشمی تأیید کنید.

## 🧪 تست‌های داخلی

```bash
python tools/check_utils.py       # تاریخ شمسی، تبدیل عدد فارسی و آیکن‌ها (پایتون)
node tools/check_js.js            # همان تبدیل‌ها در سمت مرورگر (باید عین پایتون باشد)
python tools/check_templates.py   # قالب‌ها، مسیرها، فیلترها، آیکن‌ها و استاتیک‌ها
python tools/check_css.py         # ساختار CSS، بریک‌پوینت‌ها، خوانایی فونت‌ها و نکات موبایل
```

`check_templates.py` علاوه بر مسیرها و فیلترها بررسی می‌کند که همه آیکن‌های استفاده‌شده
در اسپرایت وجود داشته باشند و هیچ ایموجی جامانده‌ای در قالب‌ها و جاوااسکریپت نباشد.

## 📱 سازگاری با گوشی‌ها

روی این اندازه‌ها تنظیم شده است:

| دستگاه | عرض | چیدمان |
|---|---|---|
| گوشی‌های باریک (iPhone SE، اندروید ۳۲۰) | ۳۲۰–۳۴۰ | یک‌ستونه فشرده، بدون برچسب اضافه |
| گوشی‌های کوچک | ۳۴۱–۴۰۰ | یک‌ستونه، دکمه‌ها تمام‌عرض، مبلغ در خط جدا |
| گوشی‌های متوسط (iPhone 13 = ۳۹۰، شیائومی نوت = ۳۹۳) | ۴۰۱–۴۳۰ | یک‌ستونه با مبلغ درشت |
| گوشی‌های بزرگ | ۴۳۱–۶۹۹ | دو ستون کارت آماری |
| تبلت کوچک و گوشی افقی | ۷۰۰–۸۱۹ | دو ستون کامل |
| تبلت | ۸۲۰–۱۰۲۳ | سه ستون فیلتر، منوی پایین |
| دسکتاپ | ۱۰۲۴+ | نوار کناری ثابت، چهار ستون |

نکات فنی که رفع شده‌اند:
- **منوی کشویی نیمه‌باز نمی‌ماند:** منو در حالت بسته با `visibility` کاملاً غیرفعال است،
  عرضش هرگز از ۸۶٪ صفحه بیشتر نمی‌شود، با انتخاب هر لینک بسته می‌شود و با چرخش گوشی
  یا تغییر اندازه صفحه وضعیتش پاک می‌شود.
- **زوم خودکار آیفون:** فونت همه فیلدها حداقل ۱۶ پیکسل است؛ سافاری آیفون اگر فونت فیلد
  کوچک‌تر باشد هنگام لمس، کل صفحه را زوم می‌کند و همین باعث به‌هم‌ریختگی و اسکرول عجیب می‌شد.
- **ارتفاع صفحه در سافاری:** از `100dvh` استفاده شده تا نوار آدرس سافاری صفحه را نبُرد.
- **نوار پایین گوشی:** `env(safe-area-inset-bottom)` رعایت شده تا روی آیفون‌های بدون دکمه
  و اندرویدهای با ناوبری اشاره‌ای، دکمه‌ها زیر نوار سیستم نروند.
- **لرزش نوار بالا در اندروید:** افکت شیشه‌ای (blur) روی موبایل خاموش شده چون در برخی
  مرورگرهای اندروید و شیائومی باعث نیمه‌رسم شدن نوار هنگام اسکرول می‌شد.
- **بدون اسکرول افقی:** همه اندازه‌های ثابت با `min()` و درصد محدود شده‌اند.

- **واحد مبلغ:** تومان (عدد صحیح، بدون اعشار).
